`go-acme/lego` is an independent, free, and open-source project.

We have been helping you automate your ACME certificates for over ten years.

`go-acme/lego` is more than just a CLI; it's a library used by thousands of developers and integrated into major projects.

- This project is not owned by a company.
- We don't have gifted domains/accounts from DNS companies.
- I'm not an employee of a company.
- Maintaining `lego` is maintaining an ACME client library, a CLI, and about +190 DNS implementations.
